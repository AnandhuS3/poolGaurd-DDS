## 🇮🇳 Drowning Detection System - India Edition

### Regional Customizations

This application has been customized for the Indian market with the following features:

#### 📱 Phone Number Format
- **Indian Mobile Numbers**: +91 followed by 10 digits
- **Validation**: Numbers must start with 6, 7, 8, or 9
- **Format**: +91 XXXXX XXXXX
- **Example**: +91 98765 43210

#### 🕐 Timezone
- **Default Timezone**: IST (Indian Standard Time)
- **GMT Offset**: +5:30
- **Timezone Code**: Asia/Kolkata
